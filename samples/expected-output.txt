==================================================
  VIRTUAL ENGINE ECU - FreeRTOS Windows Demo
==================================================

  Simulated engine temperature is read, the fan is
  controlled and CAN telemetry is transmitted.

  KEYS

  S       : Start simulation
  F       : Trigger watchdog fault (while running)
  Ctrl+C  : Exit

  Press S to start...
